# JardinDigital Domain Model

The initial domain is framework-independent and contains five concepts.

## Node

A Node is a unit of knowledge. It has an application-generated identity, a
title, and textual content. Title and content are normalized and may each be
empty, but not both at the same time. A Node exists independently of any Canvas
and does not contain coordinates.

## Edge

An Edge is a neutral relationship from one Node to another. It is not a visual
line and has no Canvas styling. Self-edges are allowed; duplicate-edge policy
is intentionally deferred.

## Resource

A Resource identifies content or a reference that may later be associated with
knowledge. For now it has only an identity and a non-empty title. Storage,
resource kinds, physical locations, and the Node/Resource relationship remain
undecided.

## Canvas and Placement

A Canvas is a named visual organization space. It does not own copies of
knowledge. A Placement references one Canvas and one existing Node and stores
that Node's finite two-dimensional position in that Canvas.

Because position belongs to Placement, the same Node can appear in multiple
Canvases at different positions. Neither Canvas nor Placement depends on React
Flow. React Flow is adopted only as the initial Presentation/UI implementation;
an adapter outside Domain will translate between its visual model and this
domain model.

## Shared knowledge

Capture, Library, and Canvas are different ways to introduce, inspect, or
manipulate the same JardinDigital knowledge. They do not own independent domain
models or databases.

## Current decisions

- Entities are readonly TypeScript interfaces created by simple functions.
- IDs are UUIDs generated by the standard Web Crypto API and lightly branded
  strings, independent of persistence.
- Dates are omitted until lifecycle behavior gives them a concrete meaning.
- A Node must have a non-empty title, non-empty content, or both.
- Titles for Resource and Canvas must not be blank.
- Edge endpoints and Placement references must not be blank.
- Placement coordinates must be finite numbers.
- No soft delete, cascade behavior, or aggregate boundary is defined.

## Decisions deferred

- Node/Resource association and cardinality
- Resource storage, kinds, and import behavior
- Persistence, repositories, SQLite, ORM, and migrations
- Managed Resource and Linked Resource
- Deletion and cascade rules
- Duplicate-edge policy
- Production visual Canvas behavior
- Global state management
