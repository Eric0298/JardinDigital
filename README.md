# JardinDigital

JardinDigital is an open-source, local-first desktop digital garden.

Principles:

- Local-first
- Offline-first
- Privacy-first
- Lightweight-first
- Open source

The project is in early development. Its current stack is Tauri 2, React,
TypeScript, and Vite.
